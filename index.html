Offsite Backup

Offsite Backup is a private, single-user tool. It copies the owner's own backup files from the owner's home server to the owner's own Google Drive, so the data survives a local disk failure.

  • It uses only the drive.file permission: it can see and change only the files it created itself, nothing else in the Drive.
  • It is not offered to anyone else, has no other users and no web front end.

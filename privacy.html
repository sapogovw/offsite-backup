Privacy Policy

Last updated: 19 November 2026

Offsite Backup is a private tool used by its owner only, to back up the owner's own files to the owner's own Google Drive.

What data it accesses

It requests only the Google Drive drive.file scope, which lets it create, read and update the files it uploaded itself. It cannot see any other files in the Drive.

How the data is used

The files are uploaded to the owner's Drive and stay there. They are not sent to, shared with or sold to anyone else, and they are not used for advertising, analytics or model training.

Storage and retention

The data is stored only in the owner's Google Drive and on the owner's own server. The owner can delete it at any time in Google Drive.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API use complies with the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue at github.com/sapogovw/offsite-backup.
